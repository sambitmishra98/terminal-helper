Place these files manually from the terminal-helper repository root:

1. Copy docs/pyfr-implicit-case-card.md to:
   docs/pyfr-implicit-case-card.md

2. Copy profession/pyfr/README.md to:
   profession/pyfr/README.md

3. Copy profession/pyfr/pyfr-json-to-ini.py to:
   profession/pyfr/pyfr-json-to-ini.py

4. Add this line to the Documentation index in the root README.md:
   - [PyFR implicit case-card workflow](docs/pyfr-implicit-case-card.md)

5. Make the converter executable:
   chmod +x profession/pyfr/pyfr-json-to-ini.py

6. Quick test:
   python profession/pyfr/pyfr-json-to-ini.py /path/to/_case_card/gmsh_summary.json --section gmsh-summary
